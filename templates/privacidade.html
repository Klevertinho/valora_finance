Privacidade

Política de Privacidade

Esta página explica, de forma simples, como a Valora Finance trata dados necessários para operação do sistema.

Dados coletados

Podemos armazenar dados de conta, empresa, movimentações financeiras, produtos, vendas, relatórios e configurações inseridas pelo usuário.

Finalidade

Os dados são usados para permitir login, exibir painéis, salvar registros, gerar relatórios e melhorar a experiência de gestão do negócio.

Armazenamento

A versão local utiliza banco de dados do próprio ambiente. A estrutura está preparada para armazenamento por conta em ambiente de produção.

Segurança

Aplicamos separação de dados por usuário e empresa no sistema. Em produção, a configuração de banco e autenticação deve seguir boas práticas de segurança.

Contato

Para dúvidas sobre privacidade, use os canais comerciais definidos pela Valora Finance.
